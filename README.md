# NodeJS Basics Assignment

## Description

This assignment demonstrates basic Node.js programs using `console.log()`.

## Files

* `app.js` – Displays Node.js messages.
* `introduction.js` – Displays personal information.

## How to Run

Check Node.js:

```bash
node -v
```

Run Task 1:

```bash
node app.js
```

Run Task 2:

```bash
node introduction.js
```

## Expected Output

**app.js**

```text
Hello, Node.js!
I am learning backend development
```

**introduction.js**

```text
Name: Soham Patil
Education: B.Tech Computer Science
Current Learning: Node.js
Goal: Full-Stack / Backend Developer
```
